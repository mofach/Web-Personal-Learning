# HTML Single Page CV

This repository contains my implementation of a structured, single-page Curriculum Vitae (CV) built primarily with HTML. The project serves as a practical assessment to demonstrate proficiency in Semantic Markup, SEO optimization, and web accessibility standards.

## Project Source

This project is based on the frontend curriculum from roadmap.sh:
**[Project URL: Single Page CV](https://roadmap.sh/projects/single-page-cv)**

## Project Goal

The goal of this project is to teach how to create a structured, single-page CV using only HTML. The focus is on laying out education, skills, and career history in a clean, semantic manner. The structure of the CV should be easily understandable by both humans and screen readers, and ready for advanced styling in future projects.

## Requirements Checklist

Here are the key requirements provided by the project, all of which have been successfully implemented:

- [x] **Semantic HTML:** Use appropriate HTML tags (e.g., `<main>`, `<header>`, `<section>`, `<article>`, `<address>`) to structure the CV.
- [x] **SEO Meta Tags:** Include essential meta tags for SEO (Title, Viewport, Description) in the `<head>` section.
- [x] **Open Graph (OG) Tags:** Add OG tags (`og:title`, `og:description`, `og:type`, `og:url`, `og:image`) for better social media sharing preview.
- [x] **Favicon:** Add a favicon linked in the head section.
- [x] **Content Sections:** Create a single-page layout with clear sections for education, skills, and career history.
- [x] **Public Repository:** URL must point to a public GitHub repository.
- [x] **Documentation:** Repository must contain a `README.md` file.
- [x] **Source Reference:** `README.md` file must contain the project URL.

## Technologies Used

- **HTML5:** For core semantic structure and accessibility.
- **Internal CSS:** Minimal styling for typography and color accents using the `<style>` tag, adhering to the separation of concerns while keeping the document contained.
